# Loopline — Privacy and Support

Last updated: 2 October 2026

Loopline is an offline Windows railway adventure published by TalkToAI, with Shaf Games branding in the application.

## Local game information

Loopline stores railway layouts, completed commissions, town progress, discovered parcels and settings locally on your device. Standard and Sandbox saves are separate. The game does not transmit these saves to the publisher. No advertising, analytics, online multiplayer, player accounts or in-game purchase service is integrated.

Hidden parcels provide fictional town points through gameplay. They have no cash value and cannot be purchased, traded or redeemed. The game's price is handled separately by the storefront.

The Unity build normally stores local data beneath your Windows user profile at `AppData/LocalLow/Shaf Games/Loopline`. Installation context can affect the exact location. Removing the application may leave local saves behind. To erase progress permanently, close the game and remove its own save folder after making any backup you want to keep. Removing saves also removes progress.

## Microsoft Store and Windows

If you acquire Loopline through Microsoft Store, Microsoft handles storefront transactions, licensing, installation and platform services under its own policies. Windows may process device or diagnostic information according to your settings. See the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).

This privacy notice does not announce Store availability or certification.

## Support

For help or privacy questions, contact [shaf@talktoai.org](mailto:shaf@talktoai.org?subject=Loopline%20support).

If reporting an issue, include the game version, Windows version and a short description. Send screenshots or logs only if you choose to; remove personal information first. Please do not send passwords, payment information or account tokens. Support messages are information you voluntarily send and are separate from the offline game's local storage.

## Ownership

This website contains only public privacy and support information. Game source code, private project files, game artwork and game binaries are not published in this repository.
